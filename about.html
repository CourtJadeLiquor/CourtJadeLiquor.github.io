写什么

本站关注四类问题：系统级语言（C++ / Rust）的设计与性能、Python 与人工智能的工程落地、量化交易的策略研究与系统开发，以及高性能算子的实现细节。内容偏向“怎么做、为什么这样做”，而不是概念罗列。

怎么组织

专题是长期方向，先给出写作计划，再逐步补全；专栏是成体系的连续阅读，把同一项目的全部文档按依赖顺序整理。首期专栏是 HPCPlatform 算子平台，收录项目全部 12 篇技术文档。

写作原则

  • 显式优先：分清“当前行为”与“未来计划”，不把猜测写成结论。
  • 锚定代码：涉及实现时给出文件与位置，方便读者自行核实。
  • 可复现：构建、测试与基准尽量给出可直接执行的命令。
  • 承认取舍：每个设计选择都有代价，写清代价比只写优点更有用。

技术栈

本站为纯静态站点，无后端依赖；排版使用原生 HTML / CSS / JavaScript，正文由项目 Markdown 文档统一渲染生成。
