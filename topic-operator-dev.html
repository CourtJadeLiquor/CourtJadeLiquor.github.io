CUDASIMD多后端

这个专题写什么

算子是把算法意图变成硬件指令的最小单元，也是性能问题最集中的地方。这个专题以一个 C++17 高性能算子平台 HPCPlatform 为样本，从数据模型、注册分发到 CPU 多版本与 CUDA 内核完整展开。

写作计划

  • 统一数据抽象：Tensor 描述符、Buffer 与零拷贝视图的单位与生命周期约定。
  • 算子自治与分发：三元组注册表、显式拒绝与三种错误码的边界。
  • CPU 多版本优化：naive / OpenMP / oneTBB / SIMD / AVX2 的组织与位精确对拍。
  • CUDA 内核：流语义、外部内存可见性、主机与设备间的拷贝路径。
  • 配置驱动：用 YAML 把算子实例化为对象，切换后端而不改业务代码。
  • 测试与基准：GoogleTest/CTest、跨后端容差与独立性能评估。
